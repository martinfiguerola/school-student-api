# 📚 School & Student API

This is a simple practice project built with **Spring Boot** to learn and implement **bidirectional relationships** using JPA/Hibernate. It focuses on a **One-To-Many** and **Many-To-One** relationship between two entities: `School` and `Student`.


## ⚙️ Tech Stack
- Java 17+
- Spring Boot
- Spring Web
- Spring Data JPA (Hibernate)
- MySQL
- Maven
- Lombok
- Bean Validation (Jakarta)

## 🚀 Getting Started

1. Clone the repository.
2. Run the application using your IDE or the terminal:

```bash
./mvnw spring-boot:run
```
3. The API will be available at: http://localhost:8080
